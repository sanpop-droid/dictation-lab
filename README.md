# Dictation Lab: แอปฝึกสะกดคำอังกฤษ (เวอร์ชันติดตั้งบนมือถือ)

เวอร์ชันนี้ใช้ได้โดยไม่ต้องเปิด Claude ติดตั้งเป็นไอคอนบนหน้าจอมือถือได้ และเล่นได้แม้ไม่มีเน็ต (หลังจากเปิดครั้งแรกแล้ว)
มือถือหนึ่งเครื่องมีผู้เล่นได้สูงสุด 5 คน แต่ละคนมีคำศัพท์ สวน ภารกิจ และการตั้งค่าแยกกัน

## ขึ้นเว็บฟรีด้วย GitHub Pages (ทำครั้งเดียว ประมาณ 10 นาที)

1. สมัครหรือล็อกอิน https://github.com (ทำบนคอมพิวเตอร์จะง่ายที่สุด)
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
   - ตั้งชื่อ เช่น `dictation-lab`
   - เลือก **Public**
   - กด **Create repository**
3. ในหน้า repo ใหม่ กดลิงก์ **uploading an existing file**
   - แตกไฟล์ zip ก่อน แล้วลาก**ของข้างในโฟลเดอร์** `dictation-lab-app` ทั้งหมดไปวาง: `index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll` และโฟลเดอร์ `icons`
   - กด **Commit changes**
4. ไปที่ **Settings → Pages**
   - ตรง Branch เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที ลิงก์จะขึ้นในหน้าเดียวกัน หน้าตาประมาณ `https://ชื่อผู้ใช้.github.io/dictation-lab/`

## ติดตั้งบนมือถือ

- **iPhone/iPad:** เปิดลิงก์ใน **Safari** แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
- **Android:** เปิดลิงก์ใน **Chrome** แล้วแตะ **ติดตั้งแอป** (หรือเมนู ⋮ → ติดตั้งแอป)

## ย้ายความคืบหน้าเดิมจาก Claude

1. ส่งไฟล์ `dictation-lab-backup-2026-10-07.json` เข้ามือถือ (LINE ถึงตัวเอง, Google Drive หรือ iCloud ก็ได้)
2. เปิดแอปที่ติดตั้งแล้ว
3. ไปที่ **ตั้งค่า (ไอคอนเฟือง) → ข้อมูล → เปิดไฟล์สำรอง** แล้วเลือกไฟล์นั้น

ผู้เล่น "บอส" (60 คำ, ดอกไม้ 87 ต้น) และ "Momo" จะเข้ามาครบ

## ข้อควรรู้

- ข้อมูลอยู่ในเครื่องที่เล่นเท่านั้น ไม่ได้ส่งไปที่ไหน
- กด **ตั้งค่า → บันทึกไฟล์สำรอง** สัปดาห์ละครั้ง แล้วเก็บไฟล์ไว้ใน Google Drive หรือ iCloud
  - ถ้าลบแอป ล้างข้อมูลเบราว์เซอร์ หรือเปลี่ยนเครื่อง จะได้กู้คืนได้
  - เปิดไฟล์สำรองซ้ำได้ ข้อมูลจะรวมกัน ไม่ซ้ำ
- **อัปเดตแอป:** อัปโหลด `index.html` และ `sw.js` ใหม่ทับใน GitHub แล้วแอปจะขึ้นแถบ "มีเวอร์ชันใหม่"
- หน้า "เพื่อน" แบบข้ามบัญชีใช้ได้เฉพาะเวอร์ชันใน claude.ai ส่วนในแอปนี้หน้านั้นจะเป็น "ผู้เล่นทุกคน" ในเครื่อง
- ถ้าเชื่อมบัญชี GitHub ใน claude.ai (Settings → Connectors) ครั้งหน้า Claude จะอัปโหลดให้ได้เลย
