# Dictation Lab — ชุด Offline

แอปเดียวที่รวมทุกอย่างไว้ ใช้ได้โดยไม่ต้องต่อเน็ต:

- ฝึกสะกดคำ เขียนประโยค และโค้ชจุดอ่อน
- บัตรคำ แบบทดสอบ และอ่านเรื่อง
- phonics และ tense
- เกม 5 แบบ
- เมนู **ข้อสอบ**: ข้อสอบฝึก 10 ชุด พร้อมเสียง ข้อที่ผิด โหมดสอบ และคำศัพท์

## เปิดใช้งาน (บนคอมพิวเตอร์)

1. แตกไฟล์ zip ไว้ในโฟลเดอร์ใดก็ได้ เช่น `Documents/Dictation Lab`
2. ดับเบิลคลิก `index.html`
   - แนะนำให้เปิดด้วย Chrome หรือ Edge เพราะมีเสียงอ่านภาษาอังกฤษในตัว
3. ครั้งแรกจะมีหน้าต้อนรับ ให้กด **"มีไฟล์สำรองจากเครื่องอื่น? เปิดไฟล์"** แล้วเลือก `ไฟล์สำรอง-ความคืบหน้า-2026-10-13.json`
   - ความคืบหน้าของบอส (60 คำ ดอกไม้ 87 ต้น) และ Momo จะกลับมาครบ

## สิ่งที่ควรรู้

- ไม่ต้องใช้เน็ต ยกเว้นฟอนต์สวยๆ ถ้าไม่มีเน็ต แอปจะใช้ฟอนต์ของเครื่องแทน
- ข้อมูลการฝึกเก็บในเบราว์เซอร์ที่เปิดใช้ ถ้าเปลี่ยนเบราว์เซอร์หรือล้างข้อมูลเบราว์เซอร์ ความคืบหน้าจะหาย
  - กด **ตั้งค่า → บันทึกไฟล์สำรอง** สัปดาห์ละครั้ง
  - ไฟล์สำรองเก็บทั้งความคืบหน้าในการฝึกคำและข้อสอบของผู้เล่นทุกคน
- ย้ายไปเครื่องใหม่: copy ทั้งโฟลเดอร์ไป แล้วเปิดไฟล์สำรองในเครื่องใหม่
- เนื้อหาในโฟลเดอร์ `exam/` สำหรับเรียนส่วนตัวเท่านั้น
